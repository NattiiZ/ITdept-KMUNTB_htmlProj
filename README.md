# IT Department Website

A responsive website developed as part of an **HTML Project** course. This project presents information about the IT Department through a simple and user-friendly web interface.

## Features

* Department information
* Course information
* Staff and lecturer profiles
* Student-related information
* Responsive web design
* Interactive web elements

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Bootstrap

## Usage

Clone the repository:

```bash id="8b7x7n"
git clone https://github.com/NattiiZ/ITdept-KMUNTB_htmlProj.git
```

Open `index.html` in your web browser to view the website.

## Purpose

This project was developed for the **HTML Project** course to practice website design, frontend development, page layout, and creating a responsive website.
